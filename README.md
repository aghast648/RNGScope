# RNGScope

RNGScope is a research-oriented project exploring whether AI-assisted methods can identify statistical weaknesses, entropy deficiencies, and deterministic structure in synthetic random sequence generators.

## Scope

All experiments use only synthetic sequences generated locally for research purposes. The project does not analyze real authentication tokens, services, or user data.

## Research Goals

- Compare classical randomness analysis methods with machine learning approaches.
- Study entropy, predictability, bias, and structural patterns in generated sequences.
- Explore quantum randomness concepts using simulators and controlled experiments.

## Roadmap

### Phase 1 - Foundation
- Synthetic random sequence generators
- Statistical analysis pipeline
- Entropy and information-theoretic measurements

### Phase 2 - AI Analysis
- Feature extraction
- Classification and anomaly detection
- Sequence modeling experiments

### Phase 3 - Quantum Comparison
- Qiskit-based experiments
- Comparison of simulated quantum randomness and classical generators
